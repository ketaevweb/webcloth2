Производительный аналог Magica Cloth 2 для веба

Физика ткани в браузере: оригинальный движок на XPBD с compute-шейдерами WebGPU и CPU-фолбэком для WebGL 2+. Десятки тысяч частиц в реальном времени — без плагинов и сборки.

Возможности движка

Ядро src/lib/cloth не зависит от фреймворков: движок можно подключить к three.js, Babylon.js или собственному рендереру.

GPU-вычисления на WebGPU

Полный XPBD-пайплайн в compute-шейдерах WGSL: интеграция, сотни тысяч связей, коллизии — без возврата данных на CPU между подшагами.

CPU-бэкенд для WebGL2

Оптимизированный решатель на типизированных массивах (SoA, ноль аллокаций в кадре). Работает везде, где есть WebGL 2+.

Аэродинамический ветер

Сила ветра считается по треугольникам: нормаль, площадь и относительный поток, плюс многооктавный шум турбулентности и порывы.

Коллайдеры

Сферы, капсулы и плоскости с трением. Капсулы анимируются каждый кадр — ткань скользит по конечностям персонажа.

Кинематические привязки

Вершины пояса юбки или петель флага управляются внешними трансформами и тянут ткань за движущимся телом с инерцией.

Структурные и изгибные связи

Дистанционные XPBD-связи по рёбрам сетки плюс изгибные связи между противоположными вершинами смежных треугольников.

Как работает симуляция

1

Подшаги

Кадр делится на 1–4 подшага с фиксированным dt — устойчивость при любом FPS.

2

Интеграция

Полуявный Эйлер: гравитация + аэродинамические силы ветра по треугольникам, ограничение скорости.

3

Решение связей

1–16 итераций XPBD: дистанционные связи с compliance (мягкость) по рёбрам и диагоналям.

4

Коллизии

Выталкивание из сфер, капсул и плоскостей с тангенциальным трением.

5

Скорости

v = (p − p_prev)/dt, демпфирование, клэмп максимальной скорости.

6

Рендер

Позиции возвращаются в геометрию three.js: WebGPU — через staged readback, CPU — напрямую.

Минимальный пример кода

import { ClothEngine } from "@/lib/cloth";

const engine = await ClothEngine.create();     // WebGPU или CPU-фолбэк
const cloth = engine.addCloth(flagGeometry, {
  pinnedPredicate: (x) => x < 0.05,            // закреплённая кромка
});
engine.settings.windStrength = 9;              // живые настройки

function frame(dt) {
  await engine.update(dt);                     // физика + синхронизация геометрии
  renderer.render(scene, camera);
}
